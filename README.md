# Стікери спільноти КМІТ

**Автор:** приклад для ШІ-напряму КМІТ, створено Claude (ШІ від Anthropic)
**Напрям:** 2. Дизайн («ШІ-дизайн»)
**Посилання:** https://kmit-khpi.github.io/design-stickers/

![Стікер «Штампуємо ідеї!»](stickers/01-shtampuiemo-idei.png)

## Що це

Набір із 8 стікерів для Telegram про те, чим живе кафедра КМІТ НТУ «ХПІ»: листове штампування, холодне витягування, кування, моделювання пластичної деформації в QForm і штучний інтелект. Сторінка-галерея дозволяє переглянути стікери, завантажити PNG/SVG і пояснює, як зібрати з них власний набір у Telegram.

| Файл | Підпис |
|---|---|
| `01-shtampuiemo-idei` | Штампуємо ідеї! — пуансон і матриця |
| `02-vytiahnuto` | Витягнуто! — кругла заготовка → алюмінієва банка (холодне витягування) |
| `03-kuiu-maibutnie` | Кую своє майбутнє — молот і ковадло |
| `04-zmodeliui-spochatku` | Змоделюй спочатку — сітка деформацій у стилі QForm |
| `05-kmit-khpi` | #КМІТ_ХПІ — бейдж спільноти |
| `06-kozhen-avtor` | Кожен — автор — студент із ноутбуком |
| `07-shi-metal` | ШІ + метал — чіп із шестернею та іскрою |
| `08-zalik-zarakhovano` | Залік зараховано — витягнутий стакан із галочкою |

Усі файли лежать у папці [`stickers/`](stickers/): PNG 512×512 з прозорим тлом (формат статичних стікерів Telegram) і SVG для друку та доопрацювання.

## Як зроблено

- **Інструмент ШІ:** Claude — за текстовим описом намалював кожен стікер як векторний SVG (контури, кольори, підписи), потім SVG перетворено на PNG. Студенти роблять подібне в Gemini.
- **Стиль:** плаский, з товстим темним контуром, білою «наліпковою» облямівкою; кольори `#121826`, `#F28C28`, `#3B6FD8`, `#F6F5F0`; шрифт підписів — Rubik (текст перетворено на криві, тож SVG виглядають однаково на будь-якому пристрої).
- **Що довелося виправляти:** частина кириличних літер спершу зламалася під час перетворення тексту на криві — помилку знайдено, переглянувши готові PNG, і виправлено.

## Як додати в Telegram

1. Відкрийте бота [@Stickers](https://t.me/Stickers) і надішліть `/newpack`.
2. Надішліть PNG 512×512 **як файл**.
3. Надішліть емодзі для стікера. Повторіть кроки 2–3 для кожного стікера.
4. Надішліть `/publish` і оберіть коротке посилання на набір.

## Ліцензія

Стікери вільні для використання спільнотою КМІТ: додавайте їх у Telegram-набори, презентації, на плакати й мерч, змінюйте та доповнюйте. Шрифт Rubik — за ліцензією SIL Open Font License.
